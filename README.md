# VASMA - Vehicle Auto Service Management System

A comprehensive vehicle service management system designed for auto workshops and service centers.

## Features

- **Customer Management** - Track customer details, vehicles, and service history
- **Job Cards** - Create and manage service job cards
- **Expense Tracking** - Record and monitor all business expenses
- **Payment Management** - Handle payments and generate receipts
- **Commission Tracking** - Manage employee commissions
- **Service Items** - Maintain service catalog with categories
- **Employee Management** - Track staff information and roles
- **Reports & Analytics** - Generate business insights and reports
- **Secure Authentication** - JWT-based authentication with session management
- **Responsive Design** - Works on desktop and mobile devices

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript (Vanilla)
- PWA Support

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication
- Bcrypt Password Hashing

## Prerequisites

- Node.js (v14 or higher)
- MySQL (v5.7 or higher)
- npm or yarn package manager
